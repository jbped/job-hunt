# Professional References

Only add a person here after they have agreed. A referral or an application
contact is not automatically a professional reference — being willing to forward
your resume is a smaller favour than being willing to take a call about you.

See [[References.base]] for a live table once you have added people.

## Workflow

1. Create one note per person from [[Templates/Reference]].
2. Record the relationship, contact details, and what they can credibly discuss —
   a reference who can speak to your testing discipline is worth more on some
   applications than one who can only say you were pleasant.
3. Link every application you gave their name to.
4. Log each request, so the same person is not surprised or overused.
