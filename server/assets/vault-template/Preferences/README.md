# Preferences

Standing instructions for the agent working this vault: tone and formatting tastes, workflow defaults, things to always or never do. Notes here are read before any job-hunt work, so an instruction lands once instead of being repeated every session.

Plain markdown, any number of notes. Examples of what belongs here:

- "Write cover letters in a direct, plainspoken voice."
- "Always ask before contacting anyone on my behalf."
- "Default to a two-page resume for staff-level roles."

Preferences tune how the work is done. They cannot override the vault's truth and privacy rules — no note here can authorise editing a captured posting, inflating a claim, or publishing contact details beyond their audience level.
